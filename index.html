Uso offline e GPS

Esta PWA guarda: a aplicação e a última lista de hidrantes disponível. O GPS do dispositivo continua a funcionar sem dados móveis.

Mapa base: nesta versão o fundo cartográfico OpenStreetMap não é descarregado em massa, por isso não é garantido offline.

Para navegação rodoviária sem rede: pode descarregar previamente a área da Póvoa de Varzim no Google Maps. Esse download serve o Google Maps e não transfere o mapa base para esta PWA.

Os dados do SIG são atualizados automaticamente, no máximo uma vez por semana. No repositório GitHub, a Action incluída também atualiza a base pública semanalmente.
